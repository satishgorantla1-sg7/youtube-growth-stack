# Contributing

Thank you for helping build YouTube Growth Stack.

1. Open or choose an issue with testable acceptance criteria.
2. Fork the repository and create a branch such as `feat/voice-consent` or `fix/job-idempotency`.
3. Read `AGENTS.md` and the closest nested instructions.
4. Keep one concern per pull request and add tests for changed behavior.
5. Run `npm run verify` and `git diff --check`.
6. Complete the pull-request template honestly, including skipped checks and risks.

Use Conventional Commit-style subjects where practical: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, or `chore:`. Never commit `.env` files, API keys, OAuth tokens, user recordings, or production data.

Please report security issues privately as described in [SECURITY.md](SECURITY.md).
