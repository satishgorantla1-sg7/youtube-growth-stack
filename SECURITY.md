# Security policy

Do not open a public issue for a vulnerability involving authentication, tenant isolation, credentials, private data, or provider abuse.

Send a private report through GitHub Security Advisories with reproduction steps, impact, and the smallest safe proof of concept. Do not access data that is not yours, perform denial-of-service testing, or spend third-party provider credits without permission.

The project is pre-1.0. Security fixes target the latest `main` branch.
