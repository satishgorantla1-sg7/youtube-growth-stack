Customer journey

From spoken intent to approved content

The agent may research and propose, but the customer controls costly generation and consequential action. Every approval attaches to an immutable version.

01 · Listen

Speak naturally

The customer describes a niche, goal, competitor, or creative direction.

Approve transcript
02 · Scope

Plan research

The agent shows sources, limits, estimated credits, and expected outputs.

Start research
03 · Discover

Collect evidence

YouTube, Apify, and Firecrawl results become normalized evidence.

04 · Decide

Rank ideas

Opportunity, fit, evidence, and originality create a transparent shortlist.

Select idea
05 · Create

Build package

Titles, thumbnail concepts, hooks, outline, script, and supporting evidence.

Approve export

Voice is the default, not the only path

Text composer, editable transcripts, keyboard controls, captions, and visible state keep the system accessible and precise.

Approval means a specific version

Any later edit produces a new artifact version and requires reapproval. The audit record identifies who approved what and when.

No autonomous publishing in MVP

The first version ends at export or copy. A later publishing integration requires a separate explicit confirmation and scoped OAuth permission.

Voice-native interface

The conversation is the control plane

The dashboard keeps speech, evidence, editable artifacts, and approvals visible at the same time.
