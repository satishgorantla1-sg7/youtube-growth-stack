Cross-tenant leak

A guessed ID must never reveal another workspace.

Control: RLS + negative pgTAP tests

Credential leak

OAuth and service secrets must never reach client code or logs.

Control: private schema + Vault + secret scan

Duplicate callbacks

Apify or other providers may deliver the same event again.

Control: unique receipt + idempotent handler

Runaway spend

Voice, scraping, and model work can outpace customer value.

Control: budgets + append-only usage ledger

Approval bypass

Edited or regenerated output must not inherit an old approval.

Control: immutable versions + state-machine tests

Lost progress

Realtime disconnects must not erase the underlying workflow.

Control: jobs/events are durable truth

Unsupported claims

Generated recommendations must show why they were made.

Control: evidence items + source evals

YouTube quota

Public SaaS demand can exhaust project quota.

Control: cache + accounting + backoff + alerts

Scraper drift

External structures and provider behavior will change.

Control: adapters + fixtures + partial results

Recovery gap

Database backups alone do not contain Storage objects.

Control: database + object recovery exercise

CI contract: format, lint, TypeScript, build, unit tests, contract tests, migration validation, pgTAP RLS tests, Playwright critical paths, secret scan, security checks, preview evidence, human approval.
